# Code of Conduct

## Our standard

Everyone participating in the AEGIS project — issues, pull requests, discussions, and all other spaces — is expected to be respectful, constructive, and honest. We are building a security tool whose entire brand is trustworthiness; the community around it must match that.

## Expected behavior

- Be kind and professional in all interactions.
- Critique code and ideas, never people.
- Accept feedback and differing design opinions gracefully.
- Report security issues responsibly (see [SECURITY.md](SECURITY.md)) — never as public issues.
- When submitting scam examples for the corpus, ensure they contain no real personal data.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks of any kind.
- Publishing others' private information without consent.
- Submitting malicious code, backdoors, or obfuscated contributions.
- Spam, self-promotion unrelated to the project, or bad-faith reports.

## Enforcement

Project maintainers may remove, edit, or reject contributions and comments that violate this code of conduct, and may temporarily or permanently ban contributors for serious or repeated violations. Reports can be made privately via GitHub by contacting the repository owner (**starboy-hub**).
